# Независимый Morphe-патч нижнего ряда Gboard (EN/RU)

Этот комплект добавляет новый патч **iOS-Style Bottom Row (English/Russian)**. Он имеет собственную регистрацию Morphe, runtime и настройку. Он не вызывает и не изменяет runtime патча Zhuyin и не зависит от включения `Zhuyin Bottom Row Key Sizes`.

## Предполагаемое поведение

- `?123` и `ABC`/`АБВ`: ширина около двух стандартных клавиш.
- Enter: около двух стандартных клавиш в обычных текстовых полях.
- Enter: около 1,5 стандартной клавиши в URI/URL-полях.
- Глобус, пробел и другие клавиши сохраняют свои действия.
- По умолчанию функция выключена; есть отдельный тумблер в настройках Gboard Patches.
- Runtime действует только при активной английской/русской клавиатуре, поддерживаемом типе поля и обнаружении ожидаемой структуры нижнего ряда внутри `SoftKeyboardView`. При несовпадении условий он не меняет ширину.

## Как применить через GitHub Actions

1. Распакуй архив.
2. В корне своего репозитория замени `Gboard-iOS-ENG-RUS-Bottom-Row-Morphe.patch`.
3. Замени `.github/workflows/build-morphe-patch.yml`.
4. Сделай Commit в GitHub.
5. Открой **Actions → Build iOS-style EN-RU bottom-row Morphe patch → Run workflow**.
6. После успешного запуска скачай артефакт `gboard-ios-eng-rus-bottom-row-morphe`.
7. Импортируй `.mpp` в Morphe. После установки включи патч и затем тумблер **Enable iOS-style bottom row** в настройках Gboard Patches.

Workflow закреплён на проверенном исходном commit `976b7495da1cc94a30ae5007a62ab6e6d28fcfba`, чтобы случайное изменение `main` не меняло базу сборки.

## Что проверено при подготовке

- `git apply --check` на чистом исходном архиве Gboard-patches проходит.
- JSON каталога и XML настроек разбираются без ошибок; SHA-256 каталога совпадает с файлом контрольной суммы.
- Java runtime и настройки прошли `javac`-проверку со stub-классами Android API.
- В runtime нет вызовов или ссылок на `GboardZhuyinBottomRowWeightRuntime`; добавлен контрактный тест на независимость и поддержку обоих переключателей (`?123` и `ABC`/`АБВ`).
- Изменения не редактируют исходники runtime Zhuyin.

**Ограничение проверки:** полноценный Gradle build здесь не выполнен — среда не может загрузить Gradle с `services.gradle.org`. Поэтому успешная компиляция Morphe ещё не подтверждена. GitHub Actions выполняет тесты и сборку; работу на устройстве нужно проверить после установки.
